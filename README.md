# Waste Collection Management System for Lusaka City Council

## Overview

The **Waste Collection Management System** is a web-based application designed to support the **Lusaka City Council** in planning, coordinating, and monitoring waste collection operations across different wards. The system streamlines daily waste collection activities by providing secure, role-based access for supervisors, drivers, and loaders.

The platform improves communication between field staff and supervisors, enhances accountability, and provides real-time updates on waste collection progress.

---

## Features

- Secure user authentication
- Role-based access control
- Ward-based waste collection management
- Task assignment and monitoring
- Collection status tracking
- Route management
- Operational reporting
- Real-time task updates

## User Roles

### Supervisor

The Supervisor oversees waste collection operations within an assigned ward.

#### Responsibilities

- Assign waste collection tasks
- Monitor collection progress
- Review operational reports
- Track collection status
- Manage drivers and loaders

---

### Driver

The Driver is responsible for transporting waste and completing assigned collection routes.

#### Responsibilities

- View assigned collection routes
- Update trip progress
- Report route completion
- Update collection status

---

### Loader

The Loader assists in collecting and loading waste during scheduled operations.

#### Responsibilities

- View assigned collection tasks
- Confirm waste loading activities
- Update task completion status

---

## System Workflow

1. Supervisor logs into the system.
2. Supervisor creates and assigns collection tasks.
3. Drivers receive assigned routes.
4. Loaders receive assigned loading tasks.
5. Drivers and loaders update task progress.
6. Supervisors monitor collection activities.
7. Completed tasks are recorded and included in reports.
