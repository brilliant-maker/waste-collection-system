Waste Collection System for Lusaka City Council

A web-based waste collection management system designed to support the Lusaka City Council in coordinating waste collection operations across different wards. The system provides role-based access for supervisors, drivers, and loaders.

User Roles

Supervisor

Oversees waste collection activities within assigned wards.
Assigns and monitors collection tasks.
Reviews operational reports and collection status.

Driver

Views assigned collection routes.
Updates trip progress and collection status.
Reports route completion.

Loader

Accesses assigned collection tasks.
Confirms waste loading activities.
Updates task completion status.
